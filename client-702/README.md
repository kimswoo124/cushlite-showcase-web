# Sergio Tacchini CUSHLITE 702 Showcase

Apple 제품 페이지처럼 스크롤 위치가 영상 프레임을 직접 제어하고, 장면에 맞춰 설명 레이어가 등장하도록 만든 테니스화 쇼케이스 프로토타입입니다. 아래로 내리면 정방향, 위로 올리면 역방향으로 영상과 텍스트가 함께 움직입니다.

## 실행

```bash
cd /Users/ad1296/AIWORK/SHOWCASE
npm install
npm run dev
```

배포용 결과물은 `npm run build`로 `dist/`에 생성됩니다.

## 현재 구성

1. 스크롤로 회전·되감기 되는 히어로 영상과 제안 가격
2. 경쟁 제품 가격 비교
3. Upper → Heel → Arch → Rubber → Midsole → Cushioning → Lifestyle 순서의 독립적인 컷 전환 영상 챕터
4. 장면마다 다른 타이포그래피, 마스크 애니메이션, 화면 좌표 배치
5. 세 가지 컬러 콘셉트 아코디언
6. 주요 사양 요약과 출시 알림 모달

## 가장 자주 수정할 파일

- 제품명, 가격, 설명, 사양, 컬러: `src/data.js`
- 섹션 순서와 UI 문구: `src/App.jsx`
- 레이아웃, 색, 반응형 디자인: `src/styles.css`

현재 가격과 성능 수치는 모두 편집용 가안입니다. 실제 제품 정보가 확정되면 `src/data.js`만 바꾸면 됩니다.

가격 비교의 Sergio Tacchini 이미지는 `shoe-image/Sneakers_arranged_on_white_backg…_202608041443.jpeg`을 웹용으로 최적화해 사용합니다. 경쟁 제품 사진은 각 제품의 공식 브랜드 페이지와 판매 페이지를 참고한 편집용 이미지입니다. 상업 배포 전에는 이미지 사용 권한과 실제 국내 판매 가격을 다시 확인해야 합니다.

기능 리뷰의 텍스트는 Upper(오른쪽 중앙), Heel(왼쪽 하단), Arch(상단 중앙), Rubber(왼쪽/오른쪽 교차), Midsole(오른쪽 하단), Cushioning(왼쪽 상단), Lifestyle(오른쪽 상단)처럼 장면별로 다른 위치와 단어 단위 스크롤 모션을 사용합니다. 좁은 화면에서도 위치 차이가 유지되도록 별도의 반응형 좌표가 적용되어 있습니다.

각 기능 챕터에는 3개씩, 총 21개의 부위 콜아웃이 있습니다. 얇은 리더 라인, 앵커 점, 파트 코드, 명칭, 한 줄 설명이 영상 위에서 순서대로 조립되며 데스크톱과 모바일은 각각 별도의 좌표를 사용합니다.

챕터 스크롤 진행률 44%–58%에서는 영상이 해당 부위가 가장 잘 보이는 대표 프레임에 고정됩니다. 이 구간에서 본문, 영상, 파트 라인과 라벨이 모두 완성된 하나의 정렬 장면을 만들고, 다시 위로 스크롤하면 같은 순서를 역방향으로 해체하며 영상을 되감습니다.

### 현재 재편집 컷 구성

각 챕터는 목적에 맞는 독립적인 제품·착화 컷으로 구성했습니다. Upper, Arch, Midsole은 약 2.67초이며 두 번의 짧은 디졸브로 방향을 전환합니다. Heel은 착화 상태에서 뒤꿈치 움직임과 힐 카운터를 보여주는 10초 영상으로 구성합니다. Rubber는 풋워크 영상의 마지막 회전 동작을 제외한 6.65초와 아웃솔이 드러나는 제품 컷을 0.35초 디졸브로 연결하고, 제품 정면으로 돌아오기 전 아웃솔 프레임에서 끝냅니다. 모든 기능 영상은 챕터 진입 시 한 번 자연 재생되며, 이후 스크롤을 움직이면 해당 위치의 프레임을 정방향·역방향으로 따라갑니다.

| 챕터 | 3컷 구성 | 설명과 연결되는 포인트 |
| --- | --- | --- |
| Upper | 제품 측면 → 제품 정면 → 제품 전면·측면 | 메쉬, 측면 오버레이, 레이스 케이지 |
| Heel | 제품 좌후면 → 제품 우후면 → 제품 후면·측면 | 힐 카운터, 넓은 착지 베이스, 패딩 칼라 |
| Arch | 사선 언더풋 → 전체 아웃솔 → 중족부 근접 | 아치 아래 사출 브리지와 비틀림 지지 영역 |
| Rubber | 제품 측면 → 아웃솔 회전 노출 → 바닥 전체 → 제품 전면 | 파동형 러그, 회전 홈, 하드코트 접지 면적 |
| Midsole | 측벽 매크로 → 제품 전체 측면 → 반대 방향 측면 | 뒤꿈치 볼륨, 낮은 전족, 조각된 측벽 곡선 |
| Cushioning | 후면 착지 → 뒤꿈치 들림 → 측면 체중 이동 | 힐 충격 분산, CMEVA 압축, 다음 스텝 연결 |
| Lifestyle | 측면 정지 → 전족부 압축 → 압력 해제 | 여유로운 토 박스, 토 스프링, 자연스러운 전족부 롤링 |
